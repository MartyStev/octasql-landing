AST-Validated Read-Only SQL
Built for Local LLMs: vLLM, Ollama, Air-Gapped

Your Local LLM Writes the SQL. OctaSQL Checks It and Runs It Read-Only

OctaSQL is built for teams that run their own open-weight model (vLLM, Ollama) next to the data: it gives the model only the schema the question needs, checks its SQL and runs it read-only. The context shrinks by up to 92%, so a small model fits a large schema and answers no worse; the GPU spends about five times fewer tokens per question and answers come about twice as fast. Through a paid API, the same tokens are the bill. Cloud models (Claude, GPT) connect over the same MCP.

MEASURED RESULTS · OCTASQL 0.4.4

The Same Model, Alone and Through OctaSQL

One general open-weights LLM, served locally, answers each question three ways: alone, with the bare schema; as an MCP client of OctaSQL, through get_context and run_sql; and through OctaSQL's own pipeline. A query counts as correct when it returns the same rows as a reference query.

Question set Share of correct answers Text the model reads per question, K characters
Model alone Your model + OctaSQL OctaSQL pipeline Without OctaSQL With OctaSQL
33 public databases, 298 questions 43.5% 73.8% 73.5% ≈1.2 ≈2.8 notes added
18 more public databases, 500 questions (held-out run) 38.5% — 71.5% ≈1.3 ≈4.0 notes added
Enterprise schema, 75 tables, questions in Russian 56.9% 91.7% 94.4% ≈32.9 ≈2.5 (−92%)

Your model + OctaSQL: OctaSQL hands the model the part of the schema the question needs, with notes on columns and values. The model writes the SQL; OctaSQL validates it, runs it read-only and returns hints, such as a filter value no row holds together with the values the column does hold. The model may correct its SQL twice. Own pipeline: OctaSQL calls the LLM itself and adds its own checks.

Reading the table: through OctaSQL the same general model answers correctly about 30 percentage points more often (+30.3 on 33 databases, interval +20.1 to +40.5; +33.1 for the own pipeline on the 18 further databases). Most errors of the model alone are columns that do not exist. On the 75-table schema the prompt is 13 times shorter. On small schemas the whole schema fits, and OctaSQL sends more, not less: it adds notes and values.

How it was measured: each question run twice, accuracy averaged across databases. Results will differ on your schema, questions and model. Prompt sizes are in characters, not tokens.
